# KPIs-Dashboard-Building-Infrastructure-2026
# Project Overview

An interactive Business Intelligence dashboard developed using Microsoft Power BI to analyze and monitor Building & Infrastructure maintenance activities for 2026.
The dashboard transforms operational data into meaningful insights, helping users track maintenance performance, identify activity trends, and compare weekly and monthly KPIs.

# Objectives

Monitor Building & Infrastructure operational performance.

Analyze Corrective Maintenance (CM) and Preventive Maintenance (PM) activities.

Track weekly and monthly maintenance trends.

Provide an interactive reporting experience through Power BI.

# Key Features

Interactive Filters: Dynamic week and month slicers.

Weekly KPI Analysis: Track maintenance activities across different weeks.

Monthly Performance: Compare CM and PM activities across months.

Maintenance Comparison: Analyze Building Maintenance and Infrastructure Maintenance.

Data Visualization: Interactive charts, tables, and KPI reporting.

DAX Measures: Calculate and summarize operational performance indicators.

# Key Insights

Total Corrective Maintenance activities: 1,044.

Total Preventive Maintenance activities: 257.

Building Maintenance contributed 651 CM activities.

Infrastructure Maintenance contributed 393 CM activities.

Building Maintenance accounted for 229 PM activities.

Infrastructure Maintenance accounted for 28 PM activities.

Week 01 recorded the highest CM ROT activity, with 318 activities.
